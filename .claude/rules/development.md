# Development

## Code reusability

Always prioritize code reusability. Where there is existing hooks, utilize them instead of writing new ones. If duplicated code is observed, convert it to a reusable hook or module.

## Organization

Adhere to the organizational guidelins in `app/deezer_engine/utils/README.md` on where to place new utilities. If there is no appropriate fit, a new file/folder can be created provided this document is maintained.

When changes are made that may affect user facing funcitonality such as settings, strategy controllers, etc; maintain the `.wiki/` files for up-to-date documentation.
