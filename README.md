# Deezer Smart Playlists

Inspired by [Goofy](https://github.com/Chimildic/goofy) and [Playlist Machinery / Smarter Playlists](http://www.playlistmachinery.com/), this script aims to allow you to create your own smart playlists within Deezer.

## Setup

Get api key for your account: https://developers.deezer.com/

## Development

1. (Recommended) Set up a python venv.
```bash
python3 venv -m /path/to/venv
```

2. Navigate to venv directory and clone the repository.
```bash
cd /path/to/venv
git clone REPOSITORYLINKTBD
```

3. Activate venv and install dependencies

4. If changes are made, you may need to update requirement.txt
```py
pip freeze > requirements.txt
```
